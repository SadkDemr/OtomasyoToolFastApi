📘 Custom Step Rehberi
custom-steps.jar — JMeter JSR223 (Groovy) içinden çağrılan hazır adımlar
⚙️ Kurulum ve ortak kurallar
  1. custom-steps.jar dosyasını JMeter'ın lib/ext/ klasörüne kopyala, JMeter'ı yeniden başlat.
  2. JSR223 Sampler'da dili groovy seç ve en üste ilgili import'u yaz: 
    import customsteps.CustomStepAND
import customsteps.CustomStepANDKartlar
import customsteps.CustomStepIOS
  3. Driver'ı oluşturduğun sampler'ın sonunda paylaş, diğer sampler'larda geri al: 
    vars.putObject("driver", driver)        // driver'ı oluşturan sampler
def driver = vars.getObject("driver")   // sonraki sampler'lar
  4. Tüm metodlarda ilk parametre driver, xpath parametreleri tam xpath'tir. Liste metodlarında xpath indexsiz verilir, index'i metod ekler.
  5. Değer döndüren metodların sonucunu vars.put("Ad", ...) ile sakla, sonra vars.get("Ad") veya ${Ad} ile kullan.
  6. Metod AssertionError fırlatırsa sampler FAIL olur.
