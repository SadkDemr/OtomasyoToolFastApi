🔑 Anahtar Kelimeler

VerilenBaşlangıç koşulunu tanımlar (Given)
VeÖnceki adımı devam ettirir (And)
ÖnceÖn koşul tanımlar (Before)
SonraArdından gerçekleşen (Then)
Fakat / Amaİstisna / negatif durum (But)
DoğrulaEkran doğrulama adımı (Assert)

💬 İpuçları

  • "Alan" alanına tıkla + alt satırda "Değer" yaz → Appium otomatik type aksiyonuna çevirir
  • Editörde satır başında Boşluk yazınca keyword önerileri gelir
  • Keyword sonrası Tab / Enter ile aksiyon öneri seçebilirsiniz
  • Senaryo JSON olarak kaydedilir; farklı IDE/araçlarda kullanılabilir
  • Metin eşleştirme büyük/küçük harf duyarlıdır
